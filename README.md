# Cub Scout Pack 862 website

## Overview

This repository contains the static website for Cub Scout Pack 862. It includes the website's pages, events, approved media, and the configuration used to publish it.

## Guides

This repository has separate guides for the people who maintain the website and the people who keep its information current.

- [Maintainer's guide](docs/user-guides/maintainers/maintainers.md) — local development, code, styling, deployment, domains, and calendar integration.
- [Content editor's guide](docs/user-guides/content-editors/content-editors.md) — updating website information, reviewing it, and preparing for the new season.
